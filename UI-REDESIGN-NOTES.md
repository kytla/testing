# CTU Confessions UI Redesign

The frontend styling has been updated using `CTU Confessions Redesign.html` as the visual reference.

## Updated visual system
- Flush Mahogany `#CA4333`, Wheat `#F6D8B7`, Petite Orchid `#DBA59E`, Dark Burgundy `#700D0A`
- Archivo for interface text, Source Serif 4 for confession/comment copy, IBM Plex Mono for identifiers and counters
- Warm paper page background, cream paper-slip surfaces, burgundy borders, and offset paper-stack shadows
- Squared 4–8px corners, stamped confession numbers, category tags, and thicker pressable button edges

## Updated frontend screens/components
- Welcome, register, login, and password reset
- Home confession deck and confession cards
- Explore search, category filters, sort controls, and confession list
- New confession composer and category selection
- Profile ID-card treatment, account editing, stats, and confession history
- Bottom navigation, form fields, alerts, comments sheet, and reaction controls

## Scope protection
Only frontend presentation files, shared UI components, theme tokens, and Tailwind design tokens were changed. Authentication services, validation, contexts, data models, API/database logic, and other backend/business logic files were left unchanged.
